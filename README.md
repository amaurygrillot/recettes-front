# recettes-front

Web front end of « Il en reste un peu », a recipe library for family and friends (React, TypeScript, Tailwind). The REST API
lives in the sibling repository `recettes-back`.

```bash
nvm use            # Node 26, see .nvmrc
npm install
npm run dev        # http://localhost:5173, the components are on /styleguide
npm run lint && npm run build && npm run test
```

Start with [CLAUDE.md](CLAUDE.md) and the [docs](docs): the stack decisions, the engineering standards, the design tokens and
the setup plan.
